Run node server.js in this folder, then open http://localhost:8080. Open the casing fully to reveal the vowel explorer. Drag a rectangle to select and hear audio excerpts. Data: newly extracted timestamped Praat/Burg 20 ms voiced formant estimates, 22,050 Hz WAV. Selection groups timestamp-adjacent frames, with 0.65–1.8s excerpts; it does not identify syllables or guarantee vowel labels. Original CSV preserved for reference. Three.js requires internet CDN access.
